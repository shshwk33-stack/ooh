TRANSIT ATLAS — 통합 대시보드

실행: ZIP 압축을 푼 뒤 TRANSIT_ATLAS_FINAL.html을 Chrome 또는 Edge에서 여세요.
별도 설치·실행 서버 없이 기본 입력으로 사용할 수 있습니다.

자료 연결은 좌측 ‘데이터 관리’에서 진행합니다.
- 전체 자료: 통합입력_기본자료.json과 같은 형식으로 작성해 JSON 가져오기
- 후보지 자료: 후보지역_입력양식.csv 작성 후 CSV 가져오기
- API: 데이터연동규격.md에 맞는 JSON 응답 주소를 입력하고 API 연결

가중치·지도·선택 상세·비교표·민감도는 같은 입력을 공유합니다.
운행 조건의 차량·운행일 필터는 ‘차량·운행일 선택’을 펼쳐 사용합니다.

기본 입력의 후보 점수·좌표 앵커·GPS는 시나리오 자료이며, 행정경계는 2013년 공개자료입니다.
미확보 도로·Bootstrap 결과는 연결 전까지 비워 두고 연결된 값만 표시합니다.
원격 API는 해당 서버의 CORS 설정이 필요하며 인증정보는 서버에서 관리하세요.
