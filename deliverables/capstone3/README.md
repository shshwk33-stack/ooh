# Transit OOH · 캡스톤디자인2 3차 발표

**10장 · 16:9 · 약 9분.** 정보통신공학과의 중간 진행 보고를 위한 자료다. 데이터 확보 방법, 확보한 범위, 입력 검증, 시스템 구현에 집중했다. 후속 3~4회 발표 계획도 포함했다.

## 사용할 파일

- `Transit_OOH_Capstone_3rd.pptx`: 편집 가능한 발표 자료. 각 슬라이드의 발표자 노트에 대본과 근거를 넣었다.
- `Transit_OOH_Capstone_3rd.pdf`: 동일한 10장 PDF. 제출·빠른 열람용.
- `Transit_OOH_Capstone_3rd_Speaker_Notes.docx`: 약 9분 대본, 예상 질문 10개, 자료 해석 메모. 편집 가능.
- `Transit_OOH_Capstone_3rd_Speaker_Notes.pdf`: 대본·질의응답의 PDF 버전.
- `Transit_OOH_Capstone_3rd_Preview.png`: 전체 슬라이드 미리보기.
- `presentation_validation.json`: 장수·렌더링·본문 누락 검사와 파일 해시, 지도 및 실제 브라우저 확인 근거.

PPT의 제목·본문·표·구조도·가중치 그림은 편집 가능한 도형과 텍스트다. 지도와 실제 앱 화면은 이미지다. 글꼴은 Noto Sans CJK KR을 사용했으며, 해당 글꼴이 없는 PC에서는 PDF로 동일한 배치를 확인할 수 있다.

## 10장 구성

1. 표지 — 데이터 확보와 분석 시스템 구현
2. 연구의 흐름 — 1·2차 발표에서 이번 단계로
3. 확보 방법 — View-T 공식 다운로드와 Expert 절차
4. 연구 지역 — 마포구 16개 동과 408개 도로 구간
5. 자료 현황 — 확보한 네 종류와 추가로 필요한 자료
6. 입력 검증 — 도로 번호·기간·단위 일치 확인
7. 시스템 구현 — GPS 처리와 집계자료 처리의 구조
8. 계산 방식 — 이동·공간 점수와 사용자 가중치
9. 대시보드 — 실제 실행 화면과 기능 확인
10. 다음 단계 — 남은 3~4회 발표 계획

## 자료의 해석

지도는 사용자가 제공한 View-T 원본의 공간 형상을 표시했다. 2023년 경계와 2024년 도로망의 참고 중첩이며, 연도 간 경계 동일성을 검증한 분석 지도로 설명하지 않는다. 408개는 공급자가 마포구에 할당한 도로 구간 수다.

대시보드 이미지는 현재 프로그램을 직접 실행한 화면이다. **입력과 후보 16개는 합성 데이터**이며, 실제 마포구의 16개 동과 같은 분석 대상이 아니다. 외부 배경지도는 끄고 합성 위치·경로 레이어를 표시했다.

인구 CSV는 토큰키 때문에 미다운로드다. 공식 연평균 파일의 앱 변환 기능과 실제 배송 GPS도 미완료로 명시했다. 기존 자동검사 68개 통과는 프로그램 동작의 검사 결과이며, 광고효과나 실측 모델 정확도를 검증한 수치가 아니다.

## 제작·검수

제작 소스는 저장소의 `tools/capstone3/`에 있다. 확보 원본은 이 묶음에 포함하지 않았다. 입력별 날짜·단위·관측 성격은 `docs/VIEWT_COLLECTION_STATUS.md`와 파일 검사 기록에 따랐다.

PPT를 PDF로 렌더링한 뒤 10장 전체를 시각 검토했다. 모든 네이티브 본문 문장이 PDF에 남아 있는지, 글자 깨짐·슬라이드 밖 도형이 없는지 검사했다. 앱은 실제 브라우저에서 가중치 50:50→60:40 변경과 결과 표시 갱신, 오류 메시지 0건을 확인했다.
