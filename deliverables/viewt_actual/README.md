# 마포구 View-T 실제 자료 · 발표용 연구 산출물

2026-10-16 제작. 출처: 한국교통연구원 KTDB View-T, <https://viewt.ktdb.go.kr/cong/map/page.do>.

## 포함 자료

- PNG/SVG 그림 각 6개: 동별 유입, 동 사이 O/D 관계, 집계 일관성, 대표 차량경로, Top-5 선정 빈도, 실제 날짜별 반환 통행량.
- 연구 요약표 3개: 16개 동 유입 집계, 일/주 Bootstrap 결과, 대표경로 형상 점검.
- 실행·테스트·제한의 검증 요약 JSON.

기관 원본과 개별 O/D/링크 가공표, 날짜별 원자료, 인증키는 포함하지 않는다. 이 패키지는 명시한 캡스톤·학술 연구 발표를 위한 가공 그림과 요약 결과다. 원자료 수집·전체 실험 코드 및 상세 방법은 저장소의 `docs/VIEWT_ACQUISITION_REPORT.md`와 `scripts/`를 참조한다.

## 발표할 때 지킬 해석

인구는 집계·추정 통행량이며 고유 인원이나 광고 노출 인원이 아니다. 연간 자료는 2024년 월~금 262일을 요청한 결과이며 실제 원자료의 날짜별 완전성을 보증하지 않는다. 도로망·교통량·속도는 2024년 주요도로망 408개 링크다.

일별 자료는 2024-12-02~27의 평일 20일 계획 중 19일을 확보했다. 12월 27일은 서버가 빈 결과를 반환해 제외했고 0으로 채우지 않았다. 전반 9일/후반 10일 유입 순위 Spearman 0.988235, Top-5/10 중복 100%는 이 표본의 기술적 안정성이다. 독립적인 모델 정확도·광고 효과 검증 결과가 아니다. Bootstrap은 날짜 19개 또는 주 묶음 4개를 재표집한 조건부 분석이다.

차량 경로는 상암→합정→공덕→상암의 구간별 대표경로다. 실제 배송차량 GPS나 검증된 밀크런 운행을 뜻하지 않는다. 경로 이용비율은 차량 대수가 아니다. 지도 연결선과 구역 대표 위치를 실제 개인 궤적으로 해석하지 않는다.

실제 통합 위치가치 모델 검증에는 동기간 공간 대응·POI·평일 정의와 독립 평가 기준이 추가로 필요하다. 기존 50:50/60:40 가중치 연구는 최적값을 확정한 결과가 아니다.
