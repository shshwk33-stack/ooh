# 마포구 경계 추출 도구

전국 읍면동 SHP가 파일 전달 한도를 넘을 때 사용한다. 같은 원본의 SHP/SHX/DBF/PRJ를 사용자의 브라우저에서 읽고 `sigungu_id=11140`인 활성 DBF 행에 해당하는 마포구 16개 다각형만 ZIP으로 만든다. 원자료나 인증키를 도구에 포함하지 않는다. 외부 서버 호출·추가 라이브러리·API 키·설치가 없다.

사용자용 파일은 [Mapo_boundary_helper.zip](../../deliverables/Mapo_boundary_helper.zip)이다. 압축을 풀고 HTML을 Chrome/Edge에서 열어 원본 네 파일을 선택한다. 큰 SHP는 헤더와 선택된 레코드만 부분 읽기한다. ZIP은 크기가 작은 지역 자료를 STORE 방식으로 묶는다. 원본 파일을 수정하지 않는다.

연도는 현재 수집 단계에 맞춰 **2023**으로 표시하며, 파일 헤더로 조사연도를 인증하지 않는다. 결과는 2023년 경계의 부분집합이다. 2024년 도로망과 동 코드가 같아도 경계 동일성이나 시공간 결합의 타당성을 자동 승인하지 않는다.

지원 범위는 Polygon(Shapefile 유형 5), 표준 DBF v3의 `sigungu_id`, 동일 파일 이름과 행 순서를 가진 SHP/SHX/DBF, View-T UTM_K PRJ다. UTF-8 또는 CP949 속성을 지원한다. 선택된 원본 다각형의 내용·고리·구멍·다중 부분과 DBF 행 바이트를 보존하고 파일 헤더의 크기·레코드 번호·색인·부분집합 범위만 다시 쓴다. 구조·유한 좌표·고리 닫힘을 검사하며 자기교차 같은 위상 유효성은 수신 후 GIS 엔진에서 검사한다. CPG를 출력 인코딩에 맞게 생성한다.

빌드·검증:

```bash
python scripts/package_boundary_helper.py
bash scripts/run.sh python scripts/check_boundary_helper.py
```

검증은 Node.js와 기존 개발환경의 GeoPandas를 사용한다. 합성 검사용 다각형에 대해 독립 GIS 재열기, 정확한 좌표·한글·구멍·다중 부분·원본 레코드 바이트 보존, 삭제 행 제외, 잘못된 헤더·색인·레코드·좌표 거부, 누락/다른 파일 조합 거부를 확인한다. 120MB 가상 원본에서 선택 구간만 읽는지 검사하고 생성된 HTML의 이벤트를 Node DOM 스텁으로 실행한다. 실제 브라우저 화면 검증이나 아직 수신하지 못한 원본 다각형 검증을 수행했다고 주장하지 않는다.
