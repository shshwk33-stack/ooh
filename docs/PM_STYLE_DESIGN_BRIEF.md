# PM 참고 양식을 적용하는 Transit OOH 발표 디자인 지침

분석일: 2026-10-22. 사용자 제공 PM 배터리 연구 발표파일의 **양식·배치·정보 위계만 참고**한다. 원본의 연구 내용·모델·수치·사진·도표·기관 로고·개인 프로필·저작자 표시는 새 작품으로 옮기지 않는다. 새 산출물은 기존 익명판을 보존하고 `deliverables/competition2026_pmstyle/`에 별도로 만든다.

## 원본 파일의 구조와 확인 범위

- 15장, 20×11.25인치, 16:9.
- 모든 페이지가 총 **991개 PNG 그림 객체**로 구성되어 있다. 각 슬라이드의 객체 수는 37, 47, 79, 69, 85, 86, 111, 65, 115, 63, 41, 42, 53, 58, 40개다.
- 편집 가능한 텍스트 런·도형 채우기·폰트 크기 정보가 없다. 따라서 원본 폰트명을 XML에서 확인했다고 주장할 수 없다. PDF 변환 후 추출되는 텍스트도 0자다.
- LibreOffice로 원본 PPTX→PDF를 실제 변환하고 15장 접촉시트와 개별 페이지를 시각 확인했다. 스타일 통계와 렌더는 `.cache/pm_style_reference/`에만 보존한다. 원본 연구자료와 렌더 이미지는 배포 자료에 넣지 않는다.
- 새 발표자료는 텍스트·표·도형·막대·도식 등을 편집 가능한 네이티브 PowerPoint 요소로 재구현한다. 원본의 991개 이미지 조각을 복사하는 방식은 사용하지 않는다.

## 한눈에 보이는 양식의 특징

**순백 배경 + 짙은 회색/주황 2줄 제목 + 청록색 결과 강조 + 논문형 2열 정보 구조**가 기본이다. 기존 Transit OOH 카드형 양식과 달리, 대부분의 본문을 여백 위에 바로 배치하고 도표·표·수식을 주인공으로 삼는다.

1. 좌상단 제목은 보통 두 줄이다. 위쪽은 짙은 회색, 아래쪽 핵심어는 주황이며 모두 굵은 고딕이다. 제목 아래에 작은 굵은 영문 설명을 붙이고 얇은 가로선을 놓는다.
2. 제목 옆에는 작은 노란 전구 그림이 반복된다. 새 파일에서는 일반적 아이디어 아이콘으로 직접 그린 벡터 전구를 사용할 수 있다. 원본 이미지 자체를 가져오지 않는다.
3. 왼쪽 위/오른쪽 아래의 옅은 청록 곡면과 오른쪽 위/왼쪽 아래의 살구색 원형 조각이 화면 밖에 걸쳐 있다. 정보보다 앞서지 않도록 작게 배치한다.
4. 오른쪽 위에는 얇은 가로·세로 L자 선과 주황 방사형 별표가 있다. 직접 그린 얇은 선·일반적인 별표로 재구성한다.
5. 본문 상단에는 2~3개 문장으로 요점을 제시하고 중요한 어구에 굵기·밑줄을 준다. 긴 문단을 네모 카드에 가두기보다 도표 위의 간결한 주장으로 표현한다.
6. 분석 페이지는 왼쪽에 큰 그래프, 오른쪽에 큰 핵심 수치와 그 의미를 둔다. 아래에는 작은 결과표·Fig./Table 캡션을 둔다.
7. 일정한 바닥선과 작은 연도/작품명/쪽번호가 전체를 묶는다. 원본의 학회명·학교명·로고는 계승하지 않는다.

## 색상과 적용 원칙

원본은 반투명 PNG를 겹쳐 쓰므로 그림 내부의 원색과 흰 배경 위 최종 표시 색이 다르다. 아래는 렌더 화면과 PNG 색상 분포를 함께 보고 정한 **새 양식의 권장색**이며, 원본 테마 팔레트라는 뜻은 아니다.

| 역할 | 권장색 | 적용 |
|---|---|---|
| 배경 | `#FFFFFF` | 본문 전체 |
| 제목 기본 | `#414141` | 제목 윗줄 |
| 제목 강조 | `#FF6F40` | 제목 아랫줄·핵심어 |
| 본문·표 머리 | `#16233A` | 본문, 표 헤더, 수식 |
| 주요 결과 | `#0E9384` | R 모델, 안정성, 핵심 결과 |
| 비교 색 | `#3A5BA0` | 비교 기준선 |
| 보조 회색 | `#9CA5B6` | 다른 기준선, 축, 보조 정보 |
| 옅은 청록 | `#C6E3E4` | 모서리 곡면·가벼운 강조 배경 |
| 살구 | `#FE9C7B` | 모서리 곡면 |
| 전구 | `#FFD53A` | 아이디어 아이콘 |

PNG 원색 분포에서 `#98CCCE`, `#FE4A0F`, `#16233A`, `#0E9384`, `#FF6F40`, `#3A5BA0` 등이 확인된다. 모서리 도형은 불투명한 주황 원색을 크게 쓰기보다 최종 렌더와 같은 옅은 색을 쓴다.

모델 색상은 모든 페이지에서 고정한다. 최종 자료는 A=파랑, B=회색, C50/C60=주황, R=청록이다. C50과 C60은 이 사례의 선정 집합이 같고 선 그래프에서는 같은 선으로 설명한다. 같은 색을 두 지표의 상반된 의미로 쓰지 않는다.

## 새 16:9 페이지의 배치 규격

13.333×7.5인치로 만드는 경우의 권장값이다. 숫자는 원본 폰트에서 추출한 값이 아니라 재구현을 위한 규격이다.

- 본문 왼쪽 여백 약 0.4~0.5인치, 오른쪽 0.35~0.45인치.
- 제목 위쪽 약 0.25~0.35인치. 2줄 제목 27~31pt 굵게, 영문 부제 10~12pt 굵게.
- 제목·부제 영역은 대략 위쪽 1.5~1.7인치 안에서 끝낸다.
- 본문은 14~16pt, 보조 설명 11~13pt, Fig./Table 캡션과 출처 9.5~11pt를 권장한다. 제목과 핵심 지표에만 큰 크기를 쓴다.
- 두 열은 55:45 또는 50:50. 큰 그래프/지도와 요점 설명을 나눈다.
- 결과 강조 숫자는 34~50pt. 단위와 정의를 바로 아래에 붙인다.
- 표는 남색 머리, 얇은 구분선, 흰색 또는 매우 옅은 교차행으로 정리한다. 셀 내용이 많으면 문장을 줄이고 글자를 무작정 줄이지 않는다.
- 바닥선은 y≈7.2인치, 그 위/아래 쪽번호와 작품명을 일관되게 배치한다. 본문과 겹치지 않게 한다.
- 큰 그림에는 번호·제목·단위·출처를 붙이고 본문에서 그 그림으로 무엇을 알 수 있는지 한 문장으로 설명한다.

## Transit OOH 내용에 적용할 우선순위

참고파일의 실험 결과나 논리 순서를 복제하지 않는다. 아래는 우리 실제 연구자료에 양식만 적용하는 방법이다.

- **표지:** 주황 핵심 제목과 3~4개 연구 흐름 라벨, 우리 후보 선택/데이터 흐름 도식. 학교·교수·인물·로고 없이 익명으로 구성한다.
- **배경:** 위쪽 2~3줄 문제 요약, 아래쪽 ‘상권 중심/교통 중심/기준 불확실성’ 구조도.
- **실제 입력:** 출처·연도·측정량 표와 16개 동→15개 비교 후보 흐름. 염리동은 도로 맥락 부재이며 0점이 아님을 표시한다.
- **방법:** 2열의 점수 산식/시나리오 정의와 K개 집합 선택. 수식은 편집 가능한 텍스트로 구현한다.
- **주 결과:** 실제 모델별 최악후회 막대와 오른쪽의 `0.3143 → 0.2000`을 크게 보여 준다. 바로 옆에 기본 효용 `0.4393 → 0.4273` 및 차이 `0.0120`을 넣어 절충 관계를 설명한다. 이 값을 광고효과 개선율로 표시하지 않는다.
- **선택 대안:** 최악후회 기준의 두 최적 조합과 공통 4개 동/교체 후보를 표시한다. R1/R2의 기본 효용이 다름을 함께 제시한다.
- **민감도:** K와 가중치 범위 표, 제외한 조건의 결과, 필요하면 전체 조합 Pareto 그림을 묶는다. K=3 전체 범위에서 C50=R인 결과도 남긴다.
- **외부 맥락:** 2025년 전 분기·업종 범위의 탐색적/회고적 비교임을 표시한다. A의 거래 순위상관이 C보다 높고 공통 업종에서 A 거래 비중이 대표 R보다 약간 높은 결과를 숨기지 않는다.
- **GIS:** 실제 앱 캡처 또는 실제 후보 지도와 편집 가능한 옆 설명을 조합한다. 위치표시점과 실제 배송 정차지의 차이를 유지한다.
- **기대효과:** 후보 검토와 선택 근거 제공이라는 구체적 활용을 설명한다. 측정하지 않은 비용·시간·매출 절감률은 만들지 않는다.
- **참고문헌:** 검증한 실제 자료 출처와 문헌만 넣는다. 협업 관련 내용은 사용자가 별도로 작성한다.

## 익명성과 최종 검수

- 원본 로고·학교·학과·지도교수·이름·사진·개인 URL·바닥 기관명은 모두 제외한다.
- 원본 그림 조각을 재사용하지 않아 이미지 안의 식별자가 남는 문제를 방지한다.
- PDF는 실제 새 PPTX를 변환하여 만든다. 제목·표·본문이 PDF에 남았는지 원문 대조한다.
- 15쪽 이내, 문단 누락·쪽 밖 텍스트·렌더 문자 겹침·익명 메타데이터를 검사하고 접촉시트와 주요 페이지를 눈으로 확인한다.
- 본문 수치의 근거는 `reports/public_decision/`의 현재 표·해시로 확인한다. 모서리/강조 스타일이 데이터 출처·가정·한계를 가리지 않게 한다.

이 디자인 지침은 원본의 추출 불가능한 폰트 정보를 추정으로 단정하지 않으며, 원본 연구 성과를 우리 성과로 옮기지 않는다.
