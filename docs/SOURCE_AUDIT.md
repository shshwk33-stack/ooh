- 2차 PPTX 12장: 텍스트가 수백 개 이미지 조각으로 구성되어 있다. OOXML의 그림 위치를 이용해 12장을 재구성하여 도표·수식·지도 화면을 확인했다. 슬라이드 4는 GeoPandas/Streamlit을 향후 계획으로 표시한다.

- 선택적 Refactor Brief는 패키지에 없다.
