# 연구 설계 개정과 3차 발표 내용

## 과거 PoC에서 바뀐 점

| 항목 | 과거 | 이번 구현·판단 |
|---|---|---|
| 재현 | notebook 출력과 실행순서 불명 | 원본 보존·깨끗한 커널 14셀 성공·hash·실패 회귀 테스트 |
| 시간 | GPS 점 수×5분 | 실제 경과시간; 불규칙·누락·단절 검사 |
| 공간 | 위경도 0.002도, 순서 기반 값 배정 | UTM 미터 격자; 좌표/키/기간/유형 확인 |
| 모집단 | 정차가 잡힌 6개 후보 | 사전 선언 영역의 동일 64개 격자(기본실험) |
| 이동 | 정차 방문·체류·반복 중심 | 비정차 존재시간 분리; 반복 중복계상 진단 |
| 검증 | 내부 순위·4개 가중치 | GT, 3모델+레거시, 11가중치, 57강건성 조건, 9탐지기 설정, 5격자/경계 조건, ablation/placebo/holdout/bootstrap |
| 실측 | 없음 | LaDe 이벤트·Amazon 방문지·서울 OSM 각각 확보하고 분리 분석 |
| 연구 주장 | 광고효과가 아니라 구현가능성 | 동일한 주장 한계 유지, 실제 관측 단위와 데이터 설계의 한계 추가 |

새 정차 반경·시간 기준은 엔지니어링 기본값이다. 실제 외부 검증에서 튜닝한 최적값이 아니다. 높은 노이즈/드문 표본에서 나쁜 결과도 그대로 보고했다. synthetic seed 11/42/73을 검증에 사용했으므로 이 seed 결과를 본 뒤의 향후 개선은 별도 미사용 시나리오로 재평가해야 한다.

## 3차 발표에 보고할 실질 성과

1. 원본의 165분→190분 편향·노이즈 시드별 후보 변화를 직접 재현했다.
2. 테스트 가능한 모듈·CLI·lockfile·CI와 GIS 앱이 실제 실행된다.
3. 합성 GT 216개 정차를 기준으로 F1/시간 오차를 산출하고 실패조건을 정량화했다.
4. 공개 LaDe 전체 Jilin 표본 31,415건·57기사·163기록일을 확보했다. 연속 차량 GPS와 구분하고 AOI 작업량 분석을 수행했다.
5. 실제 LaDe에서 인접 월 Top-10 유지율은 0.2–0.9였고, 기사 cluster bootstrap에서 선정확률 0.8 이상인 후보는 없었다. 관측 기사 구성과 기간에 대한 민감성을 보여주며 우월성/광고효과는 뜻하지 않는다.
6. Amazon 3,052경로·서울 OSM node 601개를 분리 확보하고 필드·좌표교란·시공간 결합 가능성을 감사했다.

## 학회 제출 전 필요한 추가 검증

- 동의받은 실제 **차량** 연속 궤적과 독립 정차 목적/시간 라벨. PDA 기사 이벤트를 차량 관측으로 대체하지 않기.
- 같은 도시·기간의 유동/생활인구, POI와 정확한 공간 지지영역. 행정동 인구를 작은 격자에 임의 배분하지 않기.
- 모델 입력과 별도로 수집한 블라인드 전문가 판단 또는 독립 노출/주목도 지표. 연구 질문·표본·평가계획을 수집 전에 고정하기.
- 관측 기사·차량 선택 편향, 각 지역의 미관측 운영, 반복 방문과 체류의 공선성 검토.
- 다른 도시/미사용 기간·실제 계절에 대한 재현; 현재 AOI 패널 내 월별 기술통계를 계절 일반화라고 확대하지 않기.
- LaDe의 라이선스 메타데이터 충돌 및 원본 발표자료 재배포 확인. 원본 GPS 공개 업로드는 별도 동의/검토 없이는 하지 않기.

학회 기여는 '최적 광고 입지 예측'보다 **이동정보를 결합하는 의사결정 분석에서 관측단위·정규화·선정 안정성이 어떻게 결과를 바꾸는가**로 정리할 수 있다. 단, 신규성에 대한 체계적 선행연구 검토와 외부 실증은 연구자가 추가해야 한다.
