# 정량 검증 범위와 독립 검증 설계

2026-10-17 추가 구현: [모델 고도화 보고](MODEL_AUDIT_REPORT.md)에 연속 가중치·정규화/내부 비중·주 단위 재표집 결과를 정리했다. 아래의 독립 검증 설계는 [현장 도구](FIELD_VALIDATION_GUIDE.md)로 구현했으며 실제 관측은 여전히 미수행이다. 주 단위 Bootstrap은 주 안의 상관을 보존하지만 주 사이 상관·계절성을 해결하지 않는다.

## 실행된 검증

기존 GPS 분석은 물리적 정차의 시간 IoU≥0.5 일대일 매칭, dwell MAE, 시간 보존을 평가한다. ns/us/ms/s Parquet 시간 정밀도, 단일 GPS spike, 300초 관측과 야간 단절, 반시각 시간대의 시간 집계, 불완전 공간 범위, 학습 정규화 동결, 실제 복원추출과 실제 순열 여부를 회귀검사한다.

새 기본 GPS 합성 시나리오는 짧은 60/90초 배송 정차, 120~900초 배송, 120/180초 긴 신호를 포함한다. GT는 120초 이상 **물리 정차**이며 배송 목적 분류 정답이 아니다. `detector_benchmark.csv`는 경로·스케줄 생성 seed 101/202/303과 별도 노이즈 seed로 만든 3가지 미사용 시나리오(혼합 배송/저속 정체/창고), 4가지 노이즈·정확도 설정, anchor/robust 2개 방법의 72회 비교다. 개발에 사용한 쉬운 경로와 분리했지만 여전히 시뮬레이터 계열 내 검증이며 실제 차량 일반화를 입증하지 않는다. `--quick`에서는 24회다.

View-T 파일 모드의 A/B/C는 GPS 모델과 데이터 단위가 다르므로 별도 결과표로 제공한다. Min–max는 현재 후보군에 상대적이며 시나리오 간 가중치 비교에는 같은 정규화를 고정한다. 모든 값이 같은 특성은 0으로 두며 숨겨진 판별력을 부여하지 않는다. Spatial 내부 .7/.3도 기존 연구 가정이다. GPS Mobility 산식의 시간·방문 지표는 유지하며, View-T 모드에서는 정차/반복 방문을 계산하지 않고 차량 통행량 대리지표라고 표시한다.

View-T 결과표는 Model A/B/C Spearman·Kendall·Top-5/10 중복률, α=0~1 순위 변화, 50:50·60:40 비교, 동일 일자 묶음 Bootstrap, 훈련 정규화 동결 시간 holdout을 포함한다. Bootstrap은 POI 고정의 영향을 포함한 조건부 안정성이다. 일자 자기상관을 모델링하지 않았으므로 모집단 신뢰구간이나 성능 검정으로 사용하지 않는다. 3일 미만 Bootstrap, 4일 미만 시간 holdout은 미실행으로 표시한다.

## 독립 검증의 사전 설계 — 아직 미실행

1. 한 자치구에서 공개/허가된 후보 지점과 시간대를 **점수를 보기 전에** 정한다. 여러 도로 규모·상권 강도를 포함하고, View-T 입력에 사용하지 않은 날짜를 확보한다. 현장 관측은 고정 시간 동안 차량 통과와 보행 통과를 별도로 계수한다. 실측 차량 GPS는 동의한 차량의 연속 기록만 사용한다.
2. 계수자를 모델 점수에 가리고, 일부 구간을 두 명이 동시에 계수해 관측자 간 차이를 기록한다. 개인 얼굴·번호판을 수집할 필요는 없다. 날씨, 공사, 휴일, 행사, 가시거리, 진행방향, 광고판 위치와 차폐를 기록한다.
3. 산식·정규화·후보군·가중치를 검증 전에 고정한다. 50:50은 기본 의사결정 설정, 60:40은 비교 가정이다. 최적 가중치를 탐색하면 외부 검증 날짜와 분리한 내부 훈련/검증이 필요하다.
4. 입력 인구/교통량과 독립 수동 계수 간 순위상관, Model A 대비 C의 paired ΔSpearman 및 Top-K 독립 계수 회수율을 보고한다. 같은 지점의 반복 관측은 독립 표본으로 세지 않고 지점/날짜 군집을 보존한다. 표본이 작으면 유의성 주장을 유보한다. 모형 간 차이의 불확실성과 동점 처리도 보고한다.
5. 배송차량의 정차 탐지는 별도 수동 시간기록 또는 독립 블라인드 주석과 비교한다. 내비게이션 추정 경로·기사 이벤트·전체 차량 통행량은 연속 밀크런 GPS의 대체 정답이 아니다.
6. 보행 통행과 차량 접촉 가능성이 높아도 광고를 실제로 봤다는 증거는 아니다. 광고 주목도/회상/전환 검증은 별도 동의된 관측 설계가 필요하다. 이번 연구의 검증 가능 목표는 **공간별 이동활동의 상대적 설명력과 선정 안정성**이다.

현재 독립 라벨을 확보하지 못했으므로 이를 산식의 가중합이나 합성 노출 정답으로 대신하지 않는다. 연구의 기여는 데이터 단위 구분·시간 정합성·감사 가능한 의사결정 분석 시스템에 있으며 새로운 광고효과 추정 이론을 검증했다고 주장하지 않는다.

## 참고 조사

- scikit-mobility 공개 정차 전처리 구현: https://github.com/scikit-mobility/scikit-mobility/blob/master/skmob/preprocessing/detection.py (원문 코드 열람). 본 프로젝트 robust 방식은 자체 구현이며 해당 라이브러리와 동등하거나 SOTA라는 주장이 아니다. 이번 비교 기준은 보존한 anchor 방식이다.
- Chengbo Zhang, Zuopeng Xiao, *Deciphering Delivery Mobility: A City-Scale, Path-Reconstructed Trajectory Dataset of Instant Delivery Riders*, arXiv:2507.11584. 공개 초록에서 배달 이벤트 사이를 내비게이션 경로로 재구성한다고 확인했다. 실제 연속 차량 GPS의 증거로 사용하지 않았다.
- LaDe/Amazon/OSM의 기존 실제 자료 기술통계는 유지하고 시공간이 다른 국내 합성/View-T 예제와 합치지 않았다. 원본 라이선스와 단위는 DATA_SOURCES.md를 따른다.
