# 경진대회 발표 메시지와 근거 배치

2026-10-21 작성. 2026-10-22 오후 5시 제출을 위한 15쪽 이내 익명 발표의 내용 설계다. [실제 실행 보고서](PUBLIC_DATA_RESEARCH_REPORT.md)의 수치와 그래프를 기준으로 문장을 맞춘다.

주 결과는 C50의 최악후회 0.3143→R의 0.2000과 그 대가인 기본 50:50 평균점수 0.4393→0.4273이다. 최적 조합 2개·공통 4개 동·대체 망원2/성산2를 함께 설명한다. 외부 거래 지표에서는 A의 순위상관이 더 높고 공통 18개 업종에서는 A의 Q1 거래 비중이 대표 R보다 조금 높다는 결과도 포함한다. 발표의 결론은 모든 지표의 우월성이 아니라 목적별 선택의 교환관계를 설명하는 시스템이다.

## 중심 문장

**공개 교통·상권 자료를 연결하고, 중요도와 자료 표현이 달라져도 선택 손실이 작은 광고 운영 후보지역을 찾는다.**

제안 작품명: **Transit OOH — 불확실성을 고려한 교통·상권 기반 후보지역 선정 시스템**

부제: 마포구 행정동 사례와 사용자 맞춤 GIS 의사결정

핵심 사용자는 배송차량 광고 운영의 초기 후보지역을 검토하는 운영자다. 실제 사용자 인터뷰나 도입 계약을 확보했다고 주장하지 않는다. 특정 후보지역의 설치·정차·운행 가능성은 별도 검토 사항이다.

## 심사 기준과 연결할 증거

| 평가 기준 | 발표에서 제시할 근거 | 주장 범위 |
|---|---|---|
| 실무 위주의 결과 | 같은 수의 지역을 선정하는 기준선과 제안 집합, 안정적인 공통 후보와 대체 후보 | 후보 검토를 지원하는 구체적 산출물 |
| 융합 | 공개 교통·상권 데이터 검사, 산업공학 최적화, 공간정보·웹 시스템 | 자료공학과 의사결정의 결합 |
| 협동성 | 사용자가 확인한 실제 역할·공유 산출물·검토 과정 | 팀 정보 없이 분업 실적을 만들지 않음 |
| 창의성 | 단일 가중치 순위에서 벗어나 선호·자료 표현의 불확실성을 공개하는 후보 집합 | 기존 최적화 기법의 응용 설계 |
| 활용성 | 자치구 입력 검증 후 다른 지역 적용, 광고·입지 사전 선별 등 | 확장 가능성으로 제시; 검증하지 않은 지역의 성과는 제시하지 않음 |

## 15쪽 권장 구성

| 쪽 | 제목 방향 | 보여 줄 자료·시각화 | 한 문장 메시지 |
|---:|---|---|---|
| 1 | 기준이 달라져도 설명할 수 있는 후보 선정 | 익명 작품명과 문제→선택→검토 흐름 | 광고 운영의 초기 지역 검토를 돕는다 |
| 2 | 교통이 많은 곳과 상권이 큰 곳은 다르다 | 실제 후보의 두 축 산점도 | 단일 지표와 고정 가중치만으로 결정을 확신하기 어렵다 |
| 3 | 운영자가 내려야 할 결정 | 후보 수 K와 가중치·자료 조건의 도식 | 같은 수의 지역을 어떤 기준으로 고를지 명시한다 |
| 4 | 확보한 실제 공개자료 | 기관·연도·단위·범위를 가진 데이터 카드 | 실측·기관 추정·합성 테스트를 구분한다 |
| 5 | 자료가 맞지 않으면 합치지 않는다 | 코드 대응·연장 검사·결측 제외의 검증 흐름 | 데이터 정합성이 모형보다 먼저다 |
| 6 | 데이터에서 후보 선택까지 | 수집→검사→점수→선택→GIS 아키텍처 | 구현 전체가 재실행 가능하도록 연결되어 있다 |
| 7 | 비교 모델과 점수 | A/B/C50/C60/R 표와 쉬운 가중합 설명 | 기존 방식과 같은 후보·K로 공정하게 비교한다 |
| 8 | 가장 불리한 조건의 선택 손실을 줄인다 | 상황별 최선 집합과 선택 집합의 차이 도식 | 제안 모델은 후보 묶음의 최악후회를 최소화한다 |
| 9 | 실험을 어떻게 검증했는가 | 주·보조 K, 시나리오, 제외조건, 외부 맥락의 구조 | 목적함수 안의 최적성과 외부 성과를 구분한다 |
| 10 | 실제 자료에서 얻은 선택 결과 | 실제 결과표·후회 그래프·모든 동점 조합·명목점수 대가 | 무엇을 포기하고 어떤 선택 위험을 줄였는지 공개한다 |
| 11 | 가정이 달라져도 유지되는가 | 가중치 순위·Top-K·분기/정의 제외 결과 | 안정성이 어떤 가정에 의존하는지 보여 준다 |
| 12 | 다른 연도 상권 자료로도 확인 | 추정 거래 비중·순위상관과 불리한 결과 | 보조 상권 맥락이며 광고효과 정답은 아니다 |
| 13 | 사용자가 직접 비교하는 GIS | 익명화한 실제 대시보드 캡처 | 가중치·후보 수 변경과 CSV 출력으로 검토할 수 있다 |
| 14 | 실제 활용과 결론 | 공통 후보/대체 후보, 적용 범위·제한 | 한 가지 정답 대신 설명 가능한 후보 선택을 제공한다 |
| 15 | 참고문헌·데이터 출처 | 확인된 문헌·공식 자료·조회연도 | 결과를 추적하고 재현할 근거를 남긴다 |

협동성은 사용자에게 실제 역할 정보를 받은 뒤 6쪽의 시스템 구성 아래나 14쪽에 간결하게 반영한다. 학교·교수·실명 표시가 익명 규정에 위배될 수 있으므로 확인한 역할명과 담당 산출물만 쓴다. 정보가 없는 현재 단계에서는 허구의 분업 표를 만들지 않는다.

## 그래프 사용 규칙

- 산점도는 실제 입력 두 성분의 차이를 보여 주고, 선택 후보와 대체 후보를 구분한다. 행정동 표시 좌표를 실제 배송 정차지로 나타내지 않는다.
- 최악후회 막대는 '정의한 시나리오의 평균 점수 손실'로 축 이름을 쓴다. 광고효과·정확도·확률 단위를 붙이지 않는다.
- 순위 그래프는 가중치에 따른 변화를 보여 준다. 순위가 바뀌었다는 사실만으로 성능 향상을 주장하지 않는다.
- 외부 거래 그래프는 분석 후보 집합의 보고된 추정 거래 비중이다. 고유 고객·마포구 전체·광고 도달률과 구분한다.
- 모든 실험 그래프에는 자료 연도, 후보 범위, K, 가정 범위, 실제/합성 구분을 짧게 남긴다.
- CSV와 그래프의 수치를 같은 결과 파일에서 생성한다. 슬라이드 문장을 위해 수치를 수작업으로 바꾸지 않는다.

## 질의응답 준비

**왜 현장관측을 하지 않았는가?**
이번 질문은 자료와 선호가 불확실한 상황의 후보지역 선택이다. 공개자료로 비교 가능한 단위를 구성하고 그 선택을 검증했다. 실제 광고 시청·반응 효과는 측정 범위에 포함하지 않았다. 현장자료 부재를 실측 결과로 채우지 않았다.

**모델이 실제 광고효과를 예측하는가?**
현재는 광고효과 예측 모델이 아니라 후보지역의 조건부 의사결정 모델이다. 실제 적용 전에는 운행·정차·매체 규정과 현장 여건을 추가 검토해야 한다.

**제안 모델이 더 좋은 것은 당연하지 않은가?**
자신의 학습 시나리오 최악후회를 최소화하므로 그 기준의 우위만으로 실증 성능을 주장하지 않는다. 제외한 분기·자료 정의의 결과와 다른 연도 상권 맥락을 함께 공개한다. 모든 목표와 K에서 우월하다고 결론 내리지 않는다.

**가중치 50:50의 근거는 무엇인가?**
사용자 판단이 정해지기 전의 중립적 비교 기준이다. 검증된 최적 비중이 아니며 60:40과 전체 범위를 함께 검사한다. 실제 운영자의 선호 범위를 입력할 수 있다.

**왜 복잡한 머신러닝을 쓰지 않았는가?**
현재 자료는 작은 행정동 집계 후보군이며 독립 광고성과 라벨이 없다. 목적과 제약이 드러나는 조합 선택 모형이 현재 연구 질문에 맞고, 가능한 모든 조합을 확인할 수 있다.

**새로운 알고리즘인가?**
강건 최적화는 기존 방법이다. 공개자료의 지원 불일치를 처리하고, 선호·자료 표현에 대한 후보 집합을 완전탐색하며, 동점과 외부 한계를 사용자가 확인하도록 구현한 응용 연구다.

**다른 지역에도 바로 적용할 수 있는가?**
코드는 확장할 수 있지만 해당 지역의 같은 연도·공간키·자료 범위 검증이 선행되어야 한다. 마포구 결과가 다른 지역의 성과를 보장하지 않는다.

## 제출 밖에서 확인할 항목

실제 팀 역할, 참가신청서·지도교수 추천서·윤리서약서의 작성·서명 상태는 사용자 확인이 필요하다. 이 작업 메모와 개인 계정이 드러나는 저장소 링크를 제출 본문에 그대로 넣지 않는다. 공개 PDF는 15쪽 이내와 익명성을 검사하고, 공고상 용량 조건도 가능하면 충족한다.
