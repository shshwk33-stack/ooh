# 공식 도로자료 연동 결과

검증일: 2026-10-15. 사용자가 받은 View-T 원본을 직접 읽어 마포구 **408개 링크**의 추정교통량·평균속도·도로 형상을 연결했다. 위치가치 모델의 성능 검증 결과가 아니라 실제 파일 입력·정합성 검사·GIS 표시 기능의 검증 결과다.

## 실제 실행 결과

| 항목 | 확인 결과 |
|---|---|
| 기준 | 2024년, 서울특별시 마포구, 평일, 연평균 일, 주요도로망 Level 5.5 |
| 교통량 | 전체·승용차·버스·트럭, 408개 고유 링크 |
| 평균속도 | 전체 차량, 동일 408개 링크 |
| 도로망 연결 | 같은 연도 네트워크의 `k_link_id`로 408/408 연결, 누락 0 |
| 공간 변환 | 원본 PRJ의 좌표계에서 EPSG:4326으로 변환, 유효 선형 검사 |
| 값 범위 | 전체 차량 1,728~138,181대/일, 트럭 133~15,886대/일, 평균속도 11~87km/h |
| 기간·지역·도로 속성 | 두 Excel 사이 일치 확인 |
| 검사 | 전체 pytest 88 passed, 1 xfailed; Ruff 통과 |

위 범위는 도로별 최소·최대값이다. 여러 도로의 교통량을 더해 마포구 고유 차량 수로 해석하지 않는다. 트럭은 전체 차량의 부분집합이며 전체 값과 다시 합산하지 않는다. 예상 실패 1건은 보존한 원본 PoC의 점 수×5분 오류이며 새 기능 실패가 아니다.

## 입력과 실행

Streamlit의 **자료 구분 → View-T · 공식 도로자료**를 선택한다. 제공자 원본 `TrafficVolume(LINK).xlsx`와 `AverageSpeed(LINK).xlsx`를 그대로 업로드할 수 있다. 연평균 일과 전체 4차종 교통량·전체 차량 속도 형식만 지원한다. 같은 형식으로 다른 자치구 자료도 입력할 수 있으며, 원본에 적힌 지역을 확인하여 표시한다.

지도를 함께 준비하려면 다음을 실행한다. 경로는 본인 파일의 실제 위치로 변경한다.

```bash
bash scripts/setup.sh
bash scripts/run.sh transit-ooh viewt-roads \
  --traffic '/path/to/TrafficVolume(LINK).xlsx' \
  --speed '/path/to/AverageSpeed(LINK).xlsx' \
  --network '/path/to/seoul_link_lev5.5_2024.zip' \
  --network-year 2024
bash scripts/run.sh streamlit run app/streamlit_app.py
```

`data/processed/viewt_official_roads/`에 `roads.csv`, `roads.geojson`, `metadata.json`을 생성한다. 앱은 해당 경로가 있으면 **저장된 공식 도로자료**를 제공한다. `--network`와 `--network-year`를 함께 생략하면 표만 생성한다. XLSX 직접 업로드 화면도 지도 없이 표부터 확인할 수 있다. 네트워크 변환에는 GeoPandas가 필요하며 저장소의 `scripts/setup.sh`로 설치된다.

전체 차량·트럭·승용차·버스·평균속도를 선택하면 도로 색과 정렬된 표가 바뀐다. 배경 타일 서비스나 외부 지도 키 없이 도로 형상을 그린다. 검증한 CSV와 집계조건 JSON을 다운로드할 수 있다. 원본·변환 결과의 SHA-256을 기록하고, 앱에서 재사용할 때 표·지도 해시와 링크 집합을 확인한다.

## 오류를 막는 처리

- 실제 Excel은 시트 크기가 `A1:A1`로 잘못 기록돼 있었다. 실제 셀을 읽어 누락 없이 복원한다.
- 파일의 서두 조건과 2줄 헤더를 검증하고, 연도·평일/주말·지역·도로등급·집계 단위가 다르면 결합을 거부한다.
- 링크 누락·중복·소수 ID·음수·빈 값·비정상 차종 합계·도로 속성 차이는 오류로 처리한다. ID의 앞자리 0은 문자열 입력에서 보존한다.
- 네트워크는 동일 연도를 명시하고 모든 표 행에 대응하는 유효 형상이 있어야 한다. 결합 전 검사가 실패하면 일부 결과를 저장하지 않는다.
- 네트워크 없이 다시 실행하면 이전 지도를 제거한다. 자료가 없으면 합성 결과로 채우지 않는다.

새 테스트 20건은 **합성한 공급자 형식의 테스트 입력**으로 오류 검출·좌표 변환·출처 보존·변경된 파일 검출·앱 지표 전환을 검사한다. 별도로 실제 업로드 파일을 CLI에서 실행하여 위 408개 연결을 확인했다. 테스트 입력을 실측 연구 표본으로 쓰지 않는다.

## 현재 산출하지 않는 항목

이 자료는 연평균 추정교통량과 집계 속도다. 실제 배송차량의 운행순서·정차시간·반복 방문, 실제 날짜별 변동, 시간대별 값, 인구량, 광고 노출 인원은 포함하지 않는다. 실제 일별 표본이 없으므로 일 단위 Bootstrap은 수행하지 않는다. 인구·POI·공통 공간단위가 없으므로 이 도로표로 통합 위치가치 점수를 만들지 않는다. 기존 가중치·민감도 모델은 유지하되 기존 합성 실험과 구분한다.

2023년 동 경계는 2024년 자료와의 버전 일치가 확인되지 않아 이 지도에 중첩하지 않았다. 주요도로망은 모든 배송 접근도로를 포함하지 않으며, 제공 네트워크의 `k_length` 단위를 임의로 해석해 이동시간을 계산하지 않는다. 인구·대표 경로 확보 후의 연결은 기관의 집계 정의와 공간 대응 확인이 선행돼야 한다.

기관 원본과 가공 도로 데이터는 Git에서 제외했다. 공개 저장소에는 코드·입력 규칙·검증 집계만 반영한다. 현재 비밀값 연결과 인구 수집 상태는 [수집 기록](VIEWT_COLLECTION_STATUS.md)에 남겼다.
