## 기존 계산식을 혼용하지 않을 것

구형 `src/model.js`는 가중합에 오전 0.91/오후 1.06 배율과 0.99 상한을 적용한다. 최신 `dashboard/src/demoModel.js`는 순수 가중합이다. 양쪽 모두 고정 예시 입력이며 실제 연구 엔진이 아니다. 이번 단계는 두 파일을 수정하지 않고 기존 60:40·30:70 결과를 회귀 기준으로 보존한다.

## Phase 1 범위와 완료 기준

1. 확보된 경계 GeoJSON의 스키마·결측·중복·좌표·위상을 검증한다.
2. 입력 SHA-256과 출처 명세를 연결하고, 오류를 임의로 보정하지 않는다.
3. 마포구 코드 `11140`을 추출하고 EPSG:4326↔5179 변환을 검사한다.
4. 지도용 GeoJSON은 EPSG:4326으로, 미터 연산 형상은 WKT CSV로 출력한다.
5. 품질보고서·파생 결과·실행 명세·로그를 생성하고 재현성을 테스트한다.
6. 실제·합성 입력을 분리하는 GPS CSV 검증 계약을 추가한다. 합성 입력으로 실측 연구결과를 대체하지 않는다.

최신 대시보드 디자인, API 토큰, DB, 기존 점수식은 수정하지 않는다. 실제 경계 처리 성공은 M/S/V·배송 활동·광고성과 분석의 완료를 뜻하지 않는다.
