# 경진대회 연구 타당성 검토

검토일: 2026-10-21. 현장관측 없이 공개자료로 수행하는 후보지역 의사결정 연구를 대상으로 한다. 기존 GPS 기능과 인구 기술통계를 보존하면서, 이번 축소형 상권·교통 모형의 주장 범위를 정한다. 실제 수치와 해석은 [실행 연구보고서](PUBLIC_DATA_RESEARCH_REPORT.md)에 정리했다.

## 실제 산출물 대조 결과

- 15개 후보·K=5의 3,003개 조합을 결과 점수표로 별도 재계산하여 최악후회 0.2000과 최적 집합 2개를 확인했다. 결과 파일 해시도 일치했다.
- C50의 명목 평균점수 0.4393과 R 대표의 0.4273을 함께 제시해야 한다. 최악후회를 줄이는 대신 명목 효용 0.0120을 포기하는 교환관계다.
- 원본 2025년 ZIP을 다시 집계하여 Q1의 모델별 보고 거래 비중을 대조했다. 공통 18개 업종의 A 비중 62.28%/대표 R 62.16%도 일치했다. 이 불리한 보조 결과를 생략하지 않는다.
- Q1 거래 순위상관은 A 0.6036, C50 0.3036이다. 거래 예측에 교통 결합이 언제나 유리하다는 주장은 지지하지 않는다.
- K=3 전체 가중치 범위에서 C50과 R 최악후회가 모두 0.2857이다. 모든 조건에서 엄격한 개선이 있다고 쓰지 않는다.
- 일반도로 전체 차량 정의를 제외한 검사에서 R의 대체 후보는 망원2에서 성산2로 바뀐다. 공통 4개는 유지되지만 모든 경우 같은 5개가 유지된다고 표현하지 않는다.
- 공식 파일 목록에서 2026년 거래 파일을 확인하지 못해 추가 연도 검사는 미실행이다. 별도 API 제공 여부까지 부재로 단정하지 않는다.

## 연구 질문과 인정 가능한 기여

**선호 비중과 자료 표현을 확신하기 어려울 때, 같은 수의 후보지역을 선정하는 여러 방법 중 조건 변화에 따른 선택 손실이 작은 집합을 찾을 수 있는가?**

후보 단위는 행정동이며, 연구 결과는 배송차량 광고 운영에서 검토할 지역의 사전 선별에 사용한다. 실제 배송 정차 위치, 반복 방문, 운행 가능한 순회 경로, 광고 시청자 수를 관측한 연구가 아니다.

최악후회 최소화와 가중합은 기존 방법이다. 새 알고리즘을 개발했다고 주장하지 않는다. 적용상의 기여는 서로 다른 공개자료의 공간·연도·집계 정의를 검증한 연결, 선호·자료 표현 불확실성을 고려한 K개 후보의 공동 선택, 전체 조합 탐색과 동점 공개, 사용자 조작과 재현을 지원하는 GIS 시스템에 있다. 선행연구 전체를 망라한 신규성 증명이나 수상 가능성은 이 검토로 보장하지 않는다.

## 모형과 최적성의 정확한 의미

공간 성분은 분기별 보고 점포 재고의 평균이고 이동 성분은 기관이 부여한 행정동의 길이 가중 차량 통행 맥락이다. 이는 인구·POI를 포함한 기존 전체 Spatial 모형과 구분하는 **축소형 모형**이다. 점포 재고와 연평균 교통은 같은 측정량이 아니다. 같은 연도의 지역 특성으로 다루고 분기 차이를 민감도 검사에 남긴다. 동별 합계 규모를 사용하면 면적·도로범위의 차이가 남으므로 면적당 밀도나 실노출 효율이라고 부르지 않는다.

고정된 자료 표현에서 각 후보 점수는 가중치의 선형함수다. 특정 K개 집합의 후회는 가능한 K개 집합의 선형 효용 중 최댓값에서 해당 집합의 선형 효용을 뺀 함수다. 따라서 가중치에 대해 볼록하고 닫힌 구간의 최댓값은 구간 양 끝에서 얻는다. 끝점 계산은 **정해진 유한 자료 시나리오와 선형 가중합 범위에서** 연속 가중치의 최악값을 포괄한다. 데이터의 사실성·미래 광고효과·미확인 시나리오까지 보장하는 정리가 아니다.

모든 K개 조합을 비교한 결과는 그 후보군·K·효용·시나리오 안에서의 최적성이다. 도로 연결, 배송 시간창, 차량 용량, 정차 허용 여부, 광고 중복 노출, 지역 간 상호작용은 포함하지 않았다. 이 제약들이 없는 상태에서 '최적 밀크런 운행계획'이나 '실무 배차 최적화 완료'라고 쓰면 안 된다.

여러 최적 집합이 나오면 전부 공개한다. 재현용 대표는 결과를 보기 전에 정한 코드 순서를 사용한다. 외부 거래 비중이 좋은 집합을 사후 대표로 바꾸지 않는다. 모든 최적 집합의 공통 후보와 대체 후보를 함께 제공하면 사용자의 추가 검토에 활용할 수 있다.

## 검증 설계의 강도와 한계

1. **알고리즘 정확성:** 독립적인 작은 완전탐색 예제, 전체 동점, 잘못된 입력, 연속 가중치 격자와 끝점 계산을 검사한다. 이 검사는 구현의 정확성을 다루며 실제 광고성과를 검증하지 않는다.
2. **기준선 비교:** 상권 단독 A, 교통 단독 B, 고정 C50/C60, R을 같은 K에서 비교한다. R은 학습 시나리오의 최악후회를 최소화하므로 여기서의 우위는 설계된 의사결정 목적에 대한 결과다.
3. **분기 제외 검사:** 한 분기를 빼고 R을 선택한 뒤 그 분기에서 평가한다. 학습 점포 평균에서도 제외 분기를 빼야 한다. 인접한 분기와 같은 지역을 사용하므로 독립적인 미래 예측 실험으로 부르지 않는다.
4. **정의 제외 검사:** 도로범위·차종·정규화 중 한 정의를 빼고 선택한 뒤 제외 정의에서 평가한다. 미리 정한 기준선과 비교하며 이 역시 가정에 대한 검사다.
5. **외부 상권 맥락:** 선택을 고정하고 다른 연도의 보고된 추정 거래 건수 비중과 점수의 순위상관을 확인한다. 이미 과거 대화에서 일부 2025 결과를 보았으므로 2025는 탐색적·회고적 검사다. 지금 작성한 프로토콜을 사전등록이나 최초 미관측 평가라고 부르지 않는다.
6. **추가 연도 확보 시:** 이전에 보지 않은 연도는 다운로드 전에 평가 연도·지표·대상 분기를 명시하고 선택 해시를 기록한다. 다만 현재 배포된 수정 과거 자료를 쓰는 회고적 실험이라는 제한은 남는다. 기존 결과를 본 뒤 설계를 정한 영향도 공개한다.

거래 비중의 분모는 **분석에 포함된 후보들의 같은 범위 합계**다. 모든 마포구·서울시의 실제 거래 비중이나 광고 도달률이 아니다. 업종 보고 범위가 다르면 후보·분기별 업종 수를 공개하고 공통으로 보고된 업종만의 보조 검사도 제공한다. 누락 업종은 0으로 대체하지 않는다. 공통 업종 범위를 결과에 맞춰 선택해서는 안 된다.

R은 집합을 선택하는 모형이므로 단일 점수 순위가 없다면 A/B/C와 같은 Spearman을 억지로 만들지 않는다. 집합은 같은 K의 지표로, 점수는 순위상관으로 비교한다. 동 하나씩 제외한 범위는 영향도 진단이며 95% 신뢰구간이 아니다. 공간 의존성을 무시한 p값으로 우월성을 선언하지 않는다.

시나리오 행은 실측 독립 표본이 아니다. 가중치가 0 또는 1일 때 같은 점수 벡터가 반복될 수 있다. 설계 행 수와 고유 벡터 수를 구분하고, 평균 후회를 기대손실로 부르지 않는다. 분기 4개를 충분한 독립 표본처럼 Bootstrap하지 않는다. 기존 19일 인구 자료의 재표집은 별도 인구 기술분석이며 이 모형의 광고성능 신뢰구간이 아니다.

## 외부 결과가 불리할 때의 결론

- A의 거래 순위상관이 C보다 높으면 그 결과를 표에 남긴다. 교통 결합이 거래 예측에 항상 유리하다는 주장을 철회하고 서로 다른 의사결정 관점을 제공한다고 설명한다.
- 일부 K에서 C와 R의 최악후회가 같으면 모두 개선되었다고 쓰지 않는다.
- 업종 범위를 통제했을 때 대표 R의 거래 비중이 A보다 낮아지면 그 결과도 함께 공개한다.
- 시나리오에서 안정적이어도 시나리오 밖의 사실적 성능은 검증되지 않을 수 있다.

연구의 성공 조건은 제안 모델이 모든 표에서 1등하는 것이 아니라, **어떤 목적·조건에서 도움이 되고 어떤 범위에서는 도움이 입증되지 않았는지 재현 가능한 근거로 설명하는 것**이다.

- 15쪽 이내 PDF로 배경·목적·해결방법·결과·기대효과·결론·참고문헌을 포함한다.
- 학교·지도교수·학과·로고·메일·계정·개인 저장소·식별 가능한 화면 경로·문서 속성을 점검한다. 연구 대상 지역명은 소속 표시와 구분한다.
- 팀 역할 정보가 오기 전에는 협동성 사실을 만들지 않는다. 확인이 필요한 사항은 제출 PDF 밖의 작업 메모로 둔다.
- 실무 기대효과는 후보 사전 검토와 조건별 대안 비교로 구체화한다. 측정하지 않은 비용 절감률·운영시간 절감률·광고효과 개선율을 기입하지 않는다.
- 테스트 통과 수와 모델의 실제 성과를 한 문장으로 혼동시키지 않는다.
