# 연구 프로토콜 v1

## 대상과 주장 범위

캡스톤2: 재현 가능한 Python GPS/GIS 시스템 구현. 산업공학회: 이동특성 추가가 **후보지 선정과 안정성**에 주는 정보를 검토한다. 광고 주목도·노출량·전환·매출 관측은 없으며 광고효과/정확도 향상을 주장하지 않는다. 기존 경로를 최적화하지 않는다.

실험 A는 서울 좌표 범위의 **synthetic** GT 스트레스 테스트다. 기본 모집단은 시뮬레이터가 정의한 차량×일이며 실제 배송차량 모집단의 추론은 불가하다. 실험 B는 확보에 성공한 공개 배송자료의 **실제 제공 관측단위**만 분석한다. 이벤트/방문지 자료를 연속 차량 GPS로 변환하지 않는다. 지리·기간·좌표계가 맞지 않는 실측 공간자료와 이동자료는 결합하지 않는다.

## 사전 정의한 질문과 검증

| 질문 | 검증 | 허용하는 해석 |
|---|---|---|
| RQ1 이동·정차 활동을 일관되게 추출하는가? | 독립 생성 GT episode 1:1 시간 IoU≥0.5 매칭, precision/recall/F1, 매칭 episode 시간 MAE, 총 정차시간 오차 | 합성 조건 내 탐지 성능; 정차 목적 분류 성능 아님 |
| RQ2 이동정보가 후보 선정에 어떤 차이를 주는가? | 같은 후보군 Static/Mobility/Integrated, Spearman/Kendall/Top-K; 특성 제거, 이동특성 행 단위 placebo | 입력 선택과 가중치에 따른 결정 차이, 모델 우열 아님 |
| RQ3 어떤 조건에서 안정적인가? | 가중치·격자·노이즈·표본주기·차량수·관측일수; 기간/차량/공간 분할; 차량 단위 bootstrap 선정확률 | 관측 설계 내 안정성; 신뢰구간은 합성 모집단 또는 제한된 관측표본 조건부 |

## 단위·정합성·결측

UTC 저장, 지역 시간대 명시; 서울 Asia/Seoul. 투영 미터 격자 기본 200m. 정차 기본 반경 30m·120초, 최대 연결 간격 180초. GPS가 드문 중단 구간과 비정상 점프는 보간하지 않는다. 움직이는 구간은 직선·일정속도 보간으로 교차 격자에 시간 분배하며 실제 도로 맵매칭이 아니다. 정차목적은 GPS만으로 식별하지 않는다.

후보군은 사전에 정의한 연구영역 격자로 고정한다. 관측이 없는 격자의 활동은 해당 표본에서 0이지만 도시 전체 미관측과 동일시하지 않는다. 공간특성 누락은 평균·0으로 채워서 Integrated를 산출하지 않고 결측으로 남긴다. Static 비교는 두 정보가 모두 있는 동일 후보군에서만 허용한다.

훈련 표본/후보군에 적합한 min–max 정규화 경계를 holdout에 고정 적용하고 범위 밖 값은 [0,1]로 clipping한다. 상수 특성은 0 처리하고 알린다. 레거시 가중치는 방문 .4/체류 .4/반복 .2 및 M:S=.6:.4로 보존한다. 새 모델은 이동시간·정차시간·방문을 동등 가중해 사전적인 투명 기준으로 사용하며 반복방문은 중복계상 진단 및 ablation 대상으로 분리한다. 이 가중치는 추정된 최적값이 아니다.

Top-K는 기본 K=5, 동점은 grid_id로 결정하여 재현한다. 순위 상관은 동점 평균순위를 사용한다. 비교 후보가 부족하거나 상수이면 상관을 NA로 표시한다. 모델별 다른 후보 제외를 허용하지 않는다. 공간분할에서 서로 다른 후보들의 순위를 직접 비교하지 않는다.

## 외부 검증 계획과 보류 조건

독립 관측한 노출/주목도/전문가 블라인드 평가를 확보하면 사전 등록한 지역·기간 holdout에서 정적모델 대비 증분 설명력을 검증한다. 입력의 가중합으로 가짜 정답을 만들지 않는다. 현재 외부 타당성, 계절 일반화, 국내 실배송 실증, 최적 가중치 추정은 보류한다. API 약관·좌표 익명화·연구윤리와 재배포는 연구자가 검토해야 한다.

## 검증 가능한 가설과 판정의 한계

- H1: 위치 오차가 없고 관측 간격이 탐지 기준을 충족하면 경과시간 기반 추출이 스케줄의 정차시간을 보존한다. 단위 테스트의 결정적 사례에서 검증하며, 노이즈가 있는 합성 실험에서는 F1과 시간 오차를 따로 보고한다.
- H2: 같은 정적 맥락을 가진 후보라도 이동활동이 다르면 결합 점수의 선정 결과가 달라질 수 있다. 같은 후보군 비교·기여도·ablation으로 기술한다. 산식에 포함된 변수의 차이가 점수에 반영되는 것은 외부 예측력 증가의 증거가 아니다.
- H3: 관측밀도·좌표오차·격자·관측 차량 구성에 따라 선정 안정성이 달라진다. 전체 실험 범위와 실패조건을 공개하며 결과를 보고 임의의 성공 기준으로 바꾸지 않는다.

이 문서는 이번 개발의 내부 분석계획이며 외부 기관에 정식 사전등록한 연구라고 주장하지 않는다. 실제 LaDe 월별 분석은 전체 관측 패널로 정의한 AOI 후보들의 탐색적 기술통계다. 미래 시점의 후보 발굴이나 광고성과 예측을 검증한 holdout이 아니다. 미관측 운영량, 기사 표본의 선택편향, 관측 계절 변화는 추가 자료 없이 분리 식별할 수 없다.
