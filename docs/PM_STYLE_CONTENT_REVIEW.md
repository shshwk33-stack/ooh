검토일: 2026-10-22. 기준 커밋 `762539d`. 기존 1·2·3차 발표와 최신 실제 자료 연구를 읽고, 새 15쪽 익명 발표에서 보존할 내용과 갱신할 내용을 정리했다. 본 문서는 내용 감사이며 연구 코드·원자료·실험 설정·기존 발표 파일은 변경하지 않았다. 팀 역할은 사용자가 별도로 작성하므로 추가 요청하거나 임의로 확정하지 않는다.

## 2. 되살려야 할 원래의 핵심

최근 15쪽 자료는 자료 정합성과 최악후회 설명이 정확하지만 앞부분이 일반적인 상권 입지 분석처럼 보일 수 있다. 원래 연구가 출발한 **물류 이동데이터의 추가 활용**을 2~4쪽에 복원하면 주제의 정체성과 융합의 이유가 더 분명해진다.

1. **운영 효율에서 데이터 활용으로:** 1차 3·5·6쪽의 핵심은 배송에서 발생하는 위치·시간·경로를 배송 관리 외의 의사결정에도 활용한다는 것이다. 이는 연구 동기로 보존할 수 있다. 모든 실제 물류기업이 데이터를 충분히 보유한다거나 지금 연구가 실제 기업 배송 GPS로 실증되었다고 확대하지 않는다.
2. **차량–공간의 관계:** 1차 6·7쪽과 2차 2·6·7쪽의 방문·체류·반복이라는 개념은 배송차량이라는 적용 대상의 이유다. 현재 공개자료 연구에서는 이를 직접 측정하지 못하므로, 기존 GPS 분석 경로의 개념과 구현으로 표시하고 실제 교통 맥락 모형과 분리한다.
3. **Transit OOH는 활용 사례:** 기존 대본도 광고효과를 입증하지 않는다고 명시했다. 광고를 위한 임의 우회나 배차 최적화가 아니라, 지역 사전 검토에 기존 자료를 더 활용하는 구상으로 설명한다.
4. **지도 이전의 공학:** 2차 3·4·5쪽과 3차 6·7쪽의 전처리→특성 추출→공간 연결→점수→GIS 흐름을 되살린다. 화면의 예쁨보다 잘못된 자료를 거부하고 입력 의미를 유지하는 분석 엔진이 핵심이다.
5. **비중에 대한 질문을 의사결정 문제로 발전:** 2차의 60:40 민감도 문제를 단순 가중치 변경 시연에 머물지 않고 현재의 사용자 선호 범위·K개 집합·동점·최악후회로 이어 준다.

권장 중심 문장:

> 배송에서 발생하는 이동정보를 새로운 지역 선택의 근거로 활용한다. 이번에는 공개 교통·상권 자료를 연결하여, 기준이 달라질 때의 후보 선택 위험을 확인하는 시스템으로 구체화했다.

이 문장 뒤에 **현재 실제 자료 모형은 배송 GPS가 아니라 기관 교통 맥락과 점포 재고의 축소형**임을 명시하면 원래 비전을 살리면서 성과를 과장하지 않을 수 있다.

## 7. 편집 시 가장 중요한 판단

**원래 비전은 더 선명하게, 입증한 범위는 더 정확하게 쓴다.** 배경에서는 물류데이터의 추가 활용과 이동형 매체의 특성을 살리고, 결과에서는 실제로 확보한 기관 교통·점포 자료의 행정동 선별만 제시한다. 모든 페이지를 방어 문장으로 채울 필요는 없다. 페이지 제목은 기여와 발견을 말하고, 측정량·범위·실제/합성 구분은 각 도표의 짧은 부제와 출처에 남기는 편이 읽기 좋다.
