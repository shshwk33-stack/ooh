이전에는 토큰 환경 연결 때문에 중단했으나 이번 세션에서 공식 `selectOneToken.do`의 `SUCCESS`를 확인하고 수집했다. 키 값은 저장소에 보존하지 않는다. 새 자료 수집에는 유효한 비밀 환경변수 또는 터미널 숨김 입력이 필요하며 기존 로컬 자료를 보는 데에는 키가 필요 없다.

## 확인한 수집 조건

- Expert: <https://viewt.ktdb.go.kr/cong/map/second_map.do>
- 기준연도 2024년, 인구 유입기준, 마포구 코드 `11140000`, 전국 출발.
- 전체 구 목적지와 16개 동 목적지를 별도로 요청했다. 유입기준의 표출단위는 출발지역 단위이므로 동별 목적지는 각각 선택해야 한다.
- 2024년 월~금 날짜 262개를 명시하는 상세 분석, 출발·도착 0~23시, 체류특성·성별·연령 전체.
- 일별은 날짜 하나씩 별도 조회했다. 12월 27일은 `all=[]` 진단을 보존했고 0으로 만들지 않았다.
- 차량은 공식 `mainPath_emd.do`, 2024년 평일 종일 전체 차량 조건이다.

현재 로컬 산출물은 기관 원본/응답 `data/raw/viewt_population/`, 변환 `data/processed/viewt_population/`, 경로 `data/processed/viewt_vehicle_paths/`, 그림·표 `data/processed/viewt_acquired_report/`다. Git에는 코드와 보고만 포함하며 기관 원자료·개별 O/D 표를 추가하지 않았다.

다음 연구 과제는 **동기간 공간 대응·POI, 평일 정의 확인, 독립 평가 기준**이다. 기존 자료를 다시 받을 필요는 없다. 실제 연속 배송 GPS는 여전히 미확보이며, 정차시간·반복 방문·광고 효과를 View-T만으로 측정했다고 주장하지 않는다.
