# View-T 자료 수집 중단 지점

기록일: 2026-10-11 (한국시간). 사용자의 요청으로 자료 수집을 여기서 중단하고 캡스톤 3차 발표 준비로 전환한다.

## 확보한 자료

| 자료 | 확인한 내용 | 남은 제한 |
|---|---|---|
| `seoul_link_lev5.5_2024.zip` | 서울 8,582개 링크 중 공급자 마포구 코드 `11140`에 해당하는 408개 링크 확인 | 주요도로망이며 모든 배송 접근도로를 포함한다고 볼 수 없음 |
| `mapo_boundary_2023.zip` | 마포구 16개 동의 경계·속성·좌표계 확인 | 2024년 도로와의 경계 버전 동일성은 미확인 |
| `TrafficVolume(LINK).xlsx` | 2024년 평일 연평균 일 추정교통량, 전체·승용차·버스·트럭, 408개 링크 | 실제 일별 운행기록이나 배송차량 GPS가 아님 |
| `AverageSpeed(LINK).xlsx` | 2024년 평일 연평균 일 전체 차량 평균속도, 408개 링크 | 화물차 전용 속도·배송 정차시간이 아님 |

교통량·속도 파일의 링크 ID는 마포구 도로망 408개와 일치하며, 두 Excel의 도로 속성도 일치했다. 이 결과는 **로컬 입력 검증**이다. 공식 연평균 자료를 기존 일별 계약에 연결하는 별도 어댑터와 대시보드 반영은 아직 완료하지 않았다. 기관 원본은 업로드 첨부 경로에 보존하며 Git에 추가하지 않았다.

2023년 경계와 2024년 자료의 정합성 확인, 기관의 집계 정의·이용조건 확인이 필요하다. 연평균 값을 날짜별로 복제하여 일별 Bootstrap을 수행하지 않는다. 기존 합성 실험 결과를 이 파일들로 검증한 실측 결과로 바꾸어 설명하지 않는다.

## 인구 통행량: 토큰키 때문에 미다운로드

사용자는 View-T Expert의 분석 화면까지 진행했으나, CSV 다운로드에 토큰키가 필요하다는 안내를 받아 **아직 인구 파일을 확보하지 못했다**. 토큰 발급·인증·다운로드가 완료되었다고 기록하지 않는다. 이번 요청에서는 신청이나 추가 수집을 진행하지 않는다.

재개할 화면: <https://viewt.ktdb.go.kr/cong/map/second_map.do>

- 기준년도: 2024년.
- 도구: 기종점 인구 통행량 분석 → 유입기준.
- 도착지역: 시군구 → 서울특별시 마포구, View-T Expert 코드 `11140000`.
- 출발지역: 전국. 표출단위: 시군구.
- 분석방법: 상세 분석.
- 기간: 2024-01-01 ~ 2024-12-31. 요일: 평일(월~금).
- 시간: 출발·도착 모두 0~23시. 체류특성은 양쪽 모두 전체 범주, 성별 전체, 연령 전체.
- 분석 화면에서 다운로드 아이콘을 누른 뒤 토큰키 요구로 중단.

기간 설정을 입력한 사실과 실제 자료의 기간별 제공 범위는 다르다. CSV를 받기 전까지 전체 연도 자료가 제공된다고 확정하지 않는다.

**유입기준에서 표출단위는 출발지역의 분포를 나눈다.** 위 조건은 마포구로 들어오는 인구의 출발 시군구 분포를 확인하기 위한 것이다. 표출단위를 읍면동으로 바꾸는 것만으로 마포구 16개 도착 동별 유입량을 얻는 것은 아니다. 동별 후보 평가에는 별도의 도착 동별 자료·공간 대응이 필요하다. 인구 통행량은 광고를 실제로 본 인원이 아니다.

다음 수집 단계는 토큰 신청·승인 조건 확인 후 위 조건의 CSV 확보와 원본 정의 검토다. 지금까지 확보한 도로·교통량·속도 파일을 다시 받을 필요는 없다. 차량 대표 경로 및 실제 밀크런 GPS도 아직 미확보다.
