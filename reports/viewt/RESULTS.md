# View-T 파일 연동 의사결정 실험

입력 분류: **synthetic**. View-T 공식 실자료 수집 여부: **not_acquired**.
자치구 코드 11440, 기간 2025-10-01–2025-10-14, 후보 16개, 14일.

## 모델과 실험

A = .7 × 정규화 인구통행 + .3 × 정규화 POI. B = 정규화 차량 통행량 대리지표. C = αB + (1−α)A, 현재 α=0.50.
기존 GPS 모델의 정차시간·방문횟수 산식은 별도 유지하며, 이 자료에서 그 지표는 측정 불가다. 인구 O/D는 목적지 유입, 통행구간 자료는 구역 통행량으로 해석한다. 둘을 합산하지 않는다. 통행량은 고유 인원·광고 노출이 아니다.

A–C 순위 Spearman=0.5794, Top-5 중복률=0.6000.
이는 의사결정 변화이며 성능 향상의 증거가 아니다. 50:50·60:40·0~100%를 같은 후보군/정규화에서 비교했다. 60:40은 과거 초기 가정이며 최적값이 아니다.

동일 일자를 인구·차량 자료에 함께 재표집하는 day-cluster Bootstrap 200회. 일자가 3개 미만이면 미실행한다. 점수 범위는 조건부 안정성이며 광고효과 신뢰구간이 아니다. 연속일의 자기상관은 처리하지 않아 모집단 추론에 사용할 수 없다. POI는 고정하므로 통합 점수 안정성이 높아질 수 있어 Mobility 단독 상관도 제공한다.
시간 holdout은 훈련 구간 정규화만 사용하지만 독립 광고 라벨 검증은 아니다. 실제 검증은 고정된 관측 지점·시간의 별도 수동 차량/보행자 계수와 운행 동의 GPS를 확보한 뒤 수행해야 한다.
