# Transit Atlas — standalone download

[Download the runnable ZIP](https://github.com/shshwk33-stack/ooh/raw/refs/heads/transit-atlas-download/downloads/TRANSIT_ATLAS_RUN.zip)

1. Download and extract `TRANSIT_ATLAS_RUN.zip`.
2. Open `TRANSIT_ATLAS.html` in Chrome or Edge.

Node.js installation and a local web server are not needed. The HTML includes its fonts and scripts. Scores and visualization are frontend DEMO data.
